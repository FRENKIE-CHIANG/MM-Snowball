Introduction

Multimodal large language models (MLLMs) demonstrate remarkable visual understanding, yet their reliability in interactive settings is severely undermined by hallucination snowballing: a phenomenon where initial errors amplify across conversational turns, leading to a collapse in coherence. This failure reveals a fundamental vulnerability where models progressively neglect visual grounding in favor of over-relying on polluted textual history. Existing benchmarks are predominantly confined to single-turn or two-trun VQA, which fail to capture the complex dynamics of error propagation in long-horizon interactions.

To address this, we introduce ❄️ MM-Snowball, the first work to conduct a fine-grained diagnosis and systematic exploration of hallucination snowballing in multimodal multi-turn dialogues.

MM-Snowball

Overview

The benchmark has three properties:

(1) One shared visual anchor, (2) Six progressive turns, (3) A fixed hallucinated history.

Data construction. Each dialogue stays attached to one image while the questions move from direct perception to misleading premises and a final visual check.

Overall Performance

Accuracy across six turns. Many models fall through the middle of the dialogue and only partly recover when asked to look at the image again.

Run the Evaluation

Inference uses an OpenAI-compatible vision endpoint. Scoring uses a separate yes/no judge. Aggregation computes per-turn accuracy, VFR, and SRS from the saved judgments and does not call the API again. 

export OPENAI_API_KEY="your-key"
export OPENAI_BASE_URL="https://your-endpoint/v1"

python eval/eval.py --turn 3 --model your-vision-model
python eval/score.py --input eval_outputs/your-vision-model_Turn-3.json --model gpt-5
python eval/aggregate.py --input eval_outputs/your-vision-model_Turn-{1,2,3,4,5,6}_scores.json
