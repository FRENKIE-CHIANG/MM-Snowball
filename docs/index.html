01 · THE BENCHMARK

Measure grounding under conversational pressure.

Each example starts from a real image and a caption. An adversarial dialogue then moves from a direct visual question to a misleading premise, cascading inference, and a final request to re-check the image.

Every turn has a reference answer and a hallucinated answer. During evaluation, the model sees the image, the current question, and the previous hallucinated answers as conversation history.

04 · RUN IT

OpenAI-compatible evaluation.

The included scripts work with OpenAI and compatible vision endpoints. The evaluation script injects the benchmark’s hallucinated history; the score script uses a semantic yes/no judge against the reference answer.

$ python scripts/prepare_data.py
$ python eval/eval.py \
--turn 3 --model YOUR_MODEL
$ python eval/score.py \
--input eval_outputs/...json --model JUDGE_MODEL
